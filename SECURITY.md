# Sicurezza

VelaOS è una preview: non viene dichiarato idoneo a gestire dati sensibili o carichi di produzione. Non esiste ancora una versione stabile con supporto di sicurezza garantito.

Per una vulnerabilità usare **Security → Report a vulnerability** nel repository, se disponibile, anziché una issue pubblica con exploit o dati sensibili. Includere versione/commit, passi minimi, impatto osservato e log redatti. Non effettuare prove su sistemi o dati di altre persone.

Non inviare password o chiavi. Le ISO di sviluppo con `--test` non sono release per utenti. La preview pubblica rimuove le chiavi predisposte e maschera SSH; la sessione live rimane temporanea e usa credenziali pubbliche documentate. Cambiare credenziali e verificare il sistema prima di qualsiasi uso permanente.

I manutentori confermano e correggono i problemi secondo risorse disponibili; non è promesso un tempo di risposta.
